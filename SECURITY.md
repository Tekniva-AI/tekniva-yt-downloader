# Güvenlik / Security

Güvenlik düzeltmeleri en yeni beta sürümüne uygulanır. Eski beta sürümleri için ayrı bakım taahhüdü yoktur.

Bir açık bulursanız `info@tekniva.com.tr` adresine **Tekniva YT Downloader güvenlik bildirimi** konusu ile özel olarak yazın. Etkilenen sürüm, yeniden üretme adımları, etki ve varsa önerilen düzeltmeyi belirtin. Sömürü ayrıntılarını veya kişisel dosyaları herkese açık issue'ya eklemeyin. Yanıt süreleri için garanti verilmez.

Report vulnerabilities privately to `info@tekniva.com.tr` with the affected version, reproduction steps and impact. Security fixes target the latest beta. Do not publish exploitation details or personal data in public issues.
