# Tekniva YT Downloader — beta 0.1.5

**Node.js'i artık kendiniz kurmanız gerekmiyor.** Eksik veya eskiyse uygulama onayınızı ister; resmi bileşeni uygulama klasörüne indirip doğrular ve yapmak istediğiniz işleme devam eder.

## İndirme / Downloads

- **[Windows x64 ZIP](https://github.com/Tekniva-AI/tekniva-yt-downloader/releases/download/v0.1.5-beta/Tekniva-YT-Downloader-0.1.5-Windows-x64.zip)** — uygulama, kullanım belgesi ve lisanslar.
- **[Windows x64 EXE](https://github.com/Tekniva-AI/tekniva-yt-downloader/releases/download/v0.1.5-beta/Tekniva-YT-Downloader-0.1.5-Windows-x64.exe)** — tek uygulama dosyası; aynı otomatik kurulum desteği.
- **[SHA-256 doğrulama dosyası](https://github.com/Tekniva-AI/tekniva-yt-downloader/releases/download/v0.1.5-beta/SHA256SUMS.txt)**.

Windows 10/11 64 bit. ZIP'i çıkarın veya EXE'yi yazılabilir bir klasöre koyun ve uygulamayı açın. Python, FFmpeg ve aria2 dahildir. İlk Node.js hazırlığı internet bağlantısı ve uygulamadaki onayınızı gerektirir; yönetici izni veya bilgisayara genel kurulum gerekmez. Sonraki kullanımlarda yerel kopya yeniden kullanılır.

## Yenilikler

- Node.js 22+ varlığı ve sürüm uyumluluğu kontrolü; yerel kopya önceliği.
- Resmi Node.js 22.23.3 Windows x64 ZIP'i için sabit SHA-256 doğrulaması.
- Kurulum sırasında yüzde, iptal ve anlaşılır hata bildirimi; onay verilmezse işlem başlatılmaz.
- Bileşen hazırlandığında bekleyen listeleme/sıraya ekleme/indirme işlemine otomatik devam.
- Node.js ve lisansının uygulama klasöründe tutulması; PATH ve sistem ayarlarına dokunulmaz.
- Node.js bulunmayan ortamda EXE ve ZIP dağıtım testleri; güncel README ve katkı testleri.

## English

Node.js no longer requires a separate manual installation. If a compatible runtime is missing, the app asks for consent, downloads the official checksum-verified portable Node.js runtime into its own folder and resumes the original action. Both standalone EXE and ZIP are supported. No administrator access, global installation or PATH changes are required. The initial setup requires internet access. Python, FFmpeg and aria2 are included.

Unsigned beta. Existing settings and downloaded media can be retained. YouTube access restrictions and network speed still depend on the service.
