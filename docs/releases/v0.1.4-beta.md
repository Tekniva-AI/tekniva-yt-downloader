# Tekniva YT Downloader — beta 0.1.4

İlk herkese açık GitHub beta sürümü. YouTube ve YouTube Music içeriklerini seçerek MP4 veya kapaklı MP3 olarak indirin.

## İndirme / Downloads

- **[Windows x64 taşınabilir ZIP](https://github.com/Tekniva-AI/tekniva-yt-downloader/releases/download/v0.1.4-beta/Tekniva-YT-Downloader-0.1.4-Windows-x64.zip)** — önerilen paket; uygulama, kullanım belgesi ve lisanslar.
- **[Windows x64 EXE](https://github.com/Tekniva-AI/tekniva-yt-downloader/releases/download/v0.1.4-beta/Tekniva-YT-Downloader-0.1.4-Windows-x64.exe)** — tek uygulama dosyası.
- **[SHA-256 doğrulama dosyası](https://github.com/Tekniva-AI/tekniva-yt-downloader/releases/download/v0.1.4-beta/SHA256SUMS.txt)**.

Windows 10/11 64 bit ve **Node.js 22+** gerekir. Python kurulumu gerekmez; FFmpeg ve aria2 dahildir. ZIP'i yazılabilir bir klasöre çıkarıp uygulamayı açın. EXE kod imzalı değildir. Bu bir beta sürümüdür.

- Versiyonun yanında küçük, tıklanabilir Instagram simgesi: [Tekniva](https://www.instagram.com/tekniva.com.tr/).

- Otomatik Windows testleri, temiz release paketleme ve checksum dosyaları.

MP4/MP3 kalite seçimi, MP3 kapak resmi, tek video/kanal/oynatma listesi, seçili indirme, kuyruk, arama, sıralama, yedi dil ve açık/koyu görünüm bu ilk açık sürüme dahildir. Kayıt klasörü Ayarlar'dan seçilir; kanal/sanatçı/oynatma listesi alt klasörleri isteğe bağlıdır.

## Bilinen sınırlar

YouTube'un erişim kısıtları veya hız limitlerinin aşılması garanti edilmez. MP4 kapsayıcı içinde VP9/AV1/Opus akışları bulunabilir; eski oynatıcılar bunları desteklemeyebilir. MP3 320 kbps seçimi düşük kaliteli kaynağı iyileştirmez. Kapak görünümünü bazı oynatıcıların önbelleği etkileyebilir.

## English

First public beta: selected MP4/MP3 downloads, embedded MP3 cover art, queue management, search and sorting, seven UI languages, light/dark themes and optional folders. Download the Windows x64 ZIP, extract it and launch the EXE. Node.js 22+ is required separately; Python, FFmpeg and aria2 are included. Unsigned beta, Windows 10/11 x64. Access restrictions and network speed depend on YouTube.
